# Bela Visão Lentes

Guia de bolso para prescrição de lentes de contato da Bela Visão Oftalmologia: assistente de escolha, guias por tipo de lente, calculadoras e solução de problemas.

Aberto em `https://eudsonc-cmd.github.io/bela-visao-lentes/`. No iPhone, abra no Safari e use **Compartilhar → Adicionar à Tela de Início**; depois da primeira abertura, funciona sem internet.

Para publicar uma versão nova, troque `VERSION` em `sw.js`.

Guia de apoio para médicos oftalmologistas. Não substitui o exame, o guia do fabricante nem o julgamento clínico.
